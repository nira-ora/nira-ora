# Nira Ora

Simulateur 3D de suture et de soins de plaies, sur téléphone, même hors ligne.
*nira* : l'aiguille · *ora* : la vie. Conçu en Polynésie française par Brian Brigato, développeur polynésien.

**Essayer** : ouvrir la page GitHub Pages de ce dépôt sur un téléphone, puis « Ajouter à l'écran d'accueil ».

## Contenu
- 7 situations de suture, 16 situations de soins de plaies (dont l'ablation de fils et d'agrafes), 3 urgences, 12 leçons dont l'Atelier nœud.
- Cas du fenua : corail, poisson-pierre, morsure de chien, morsure de requin, chute en scooter, brûlures.
- 4 niveaux (Débutant, Intermédiaire, Avancé, Examen), bac à sable, prédiction de l'évolution des plaies, recherche, astuces et aide.

## Avertissement
Outil d'entraînement éducatif : il ne remplace pas une formation pratique encadrée. Contenus inspirés de recommandations publiques, non validés officiellement par la Direction de la santé ni par l'Université de la Polynésie française : à relire par les formateurs. La suture est un acte médical. Aucune donnée n'est collectée. Pas de marque commerciale dans l'application.

## Technique
Page web statique (three.js, modèles 3D faits avec Blender), sans serveur. Pour l'héberger : publier le contenu de ce dossier avec GitHub Pages (branche main, dossier racine).
