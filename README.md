# Nira Ora — version de démonstration

Simulateur 3D d'entraînement à la suture et aux soins de plaies, sur téléphone (hors ligne).
Cette démo est **limitée** : 2 plaies à suturer, 3 soins (ablation des fils, corail, morsure de chien), 2 urgences (hémorragie, morsure de requin), 6 leçons, niveaux Débutant et Intermédiaire.
Le reste de l'application est visible **en gris 🔒** : il fait partie de la version complète.

**Essayer** : https://nira-ora.github.io/nira-ora/ sur un téléphone, puis « Ajouter à l'écran d'accueil ».

Outil d'entraînement éducatif : il ne remplace pas une formation pratique encadrée ni un avis médical.
Corps 3D : maillage de base MakeHuman (CC0). Pas de données de patients ; aucune photo n'est envoyée.
